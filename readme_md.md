# 🥁 Virtual Drum Kit — Simulador de Bateria Web

Um simulador de bateria interativo e responsivo desenvolvido com **HTML, CSS e JavaScript puro**. O projeto permite tocar diferentes peças de bateria usando o teclado do computador ou toques diretamente na tela do celular/tablet.

## 🔗 Demonstration / Live Demo

Você pode testar a aplicação online hospedada de graça no GitHub Pages:

👉 [**Acesse o Simulador Online aqui**](https://SEU-USUARIO.github.io/NOME-DO-SEU-REPOSITORIO/?utm_source=gemini)

## ✨ Funcionalidades

* 🎵 **Sons em Alta Qualidade:** Resposta sonora imediata ao acionar cada instrumento.

* ⌨️ **Atalhos no Teclado:** Mapeamento de teclas para facilitar a tocabilidade no Desktop.

* 📱 **100% Responsivo & Multi-touch:** Otimizado para telas sensíveis ao toque em dispositivos móveis.

* 🎨 **Feedback Visual:** Efeitos e animações nos botões ao acionar cada peça do kit.

## 🚀 Como Executar o Projeto Localmente

1. **Clone o repositório:**

   ```
   git clone https://github.com/BrenoTTS/Bateria-Da-Angella.git
   
   ```

2. **Navegue até a pasta do projeto:**

   ```
   cd Bateria-Da-Angella
   
   ```

3. **Abra o projeto:**
   Basta dar um duplo clique no arquivo `index.html` ou utilizar extensões como o **Live Server** no VS Code.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica da página.

* **CSS3:** Estilização, layout (Flexbox/Grid), animações e media queries para responsividade.

* **JavaScript (ES6+):** Manipulação da DOM, escuta de eventos (`keydown`, `click`, `touchstart`) e controle da Web Audio API / objetos `Audio`.
